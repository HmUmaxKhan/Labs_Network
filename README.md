# 101 CompTIA Network+ Labs — Packet Tracer

Hands-on Cisco Packet Tracer labs based on **"101 Labs — CompTIA Network+ (N10-007)" by Paul Browning**. Each lab focuses on a single protocol, technology, or troubleshooting scenario you'll be tested on in the Network+ exam — and will actually use on the job.

## Repo Structure

Every lab lives in its own folder and contains:

- **`README.md`** — the lab objective, purpose, topology, and full command walkthrough
- **`.pkt`** — the Cisco Packet Tracer file for that lab, ready to open and complete

## How to Use This Repo

1. Make sure you have [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer) installed.
2. Pick a lab below and open its folder.
3. Read the lab's `README.md` for the objective and walkthrough.
4. Open the `.pkt` file and complete the tasks yourself before checking the walkthrough.
5. Labs are numbered to match the book — you can go in order or jump to a topic you want to practice.

> Based on hands-on labs from Paul Browning's *101 Labs* series (101labs.net). This repo is for personal study purposes only — not affiliated with or endorsed by CompTIA.
